# R’s essays

A static, read-only essay collection for GitHub Pages. Search by text or topic, open an essay, move to the next essay, or download a Markdown copy.

Use **Write essay** from the local app launchpad to start writing. Drafts save on this computer as you work. Choose **Publish** or **Publish changes** when an essay is ready. After GitHub authentication and publishing setup are complete, the local app updates this public collection automatically.

This repository contains the published reading site. Local drafts stay on this computer.
