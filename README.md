# R’s essays

A static, read-only essay collection for GitHub Pages. Search by text or topic, open an essay, move to the next essay, or download a Markdown copy.

The local authoring app stays private. This site contains only published, nondeleted essays and the fields needed to display them.

After editing essays locally, refresh this folder by running `py work/build-public-site.py` from the workspace. Review the generated `essays.json`, then commit the updated site files to the `r-essays` repository. GitHub Pages serves this folder as a static site.
